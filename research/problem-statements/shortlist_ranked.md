**Risks:** SCORER BIAS FLAG: scored by the main thread, not the sweep agents, and this statement is structurally the same shape as the team's abandoned project (multi-temporal change detection + confidence + before/after evidence artifact + provenance). ### 2. SIH26143 — Satellite oil-spill detection + AIS correlation to identify the responsible vessel
*National Technical Research Organisation (NTRO) · Software · Disaster Management · composite 76.5 · scored by sweep-agent*

**Read:** This is the single best fit in the chunk and possibly a marquee pick. The ask decomposes into (a) detect/characterise slicks from SAR/EO imagery, (b) hindcast/forecast drift with oceanographic + meteorological data, (c) reconstruct AIS vessel traffic in the origin space-time window and score suspect vessels by proximity/trajectory/behavioural anomaly. That maps almost one-to-one onto this team: Sentinel-1 SAR remote sensing, Python geospatial pipelines, a rule/decision engine for suspect scoring, a MapLibre front end showing slicks/drift/tracks, and the exact evidence-with-confidence, 'here is what we can and cannot prove' framing judges rewarded last time. Critically, the technically impressive core (drift correlation + AIS attribution + a generated evidence dossier) is a data-pipeline-and-rules problem, not a from-scratch model-training problem, so the team's ML gap barely bites. The angle: don't stop at detection like most teams will; own the full attribution narrative and ship a court-ready culprit-vessel report.

**Risks:** Oil-spill detection alone (part a) leans on SAR CV — mitigate by using the provided Zenodo Sentinel-1 dataset and existing detection approaches rather than training novel segmentation. Drift hindcasting needs public ocean-current data (Copernicus Marine / HYCOM) and some physical-oceanography research. AIS may be synthetic, which slightly caps realism but is explicitly permitted.

### 3. SIH26161 — Dam Break Inundation Modelling Using Hydrodynamic Modelling of any River
*National Technical Research Organisation (NTRO) · Software · Disaster Management · composite 72.5 · scored by sweep-agent*

**Read:** Rambling and technically naive in places (it conflates landslide-dam breach with engineered dam failure, and prescribes SPH and Delft3D as if they were interchangeable), but the operational need behind it is real and NTRO-relevant, and the datasets are named as open in the PS itself: Sentinel/Landsat plus SRTM/ASTER DEM. ### 6. SIH26079 — AI-Based Forecast Bust Detection for Medium-Range Weather Forecasts

### 7. SIH26066 — OceanEmbed — Satellite Embedding-Based Deep Learning Framework for Reconstruction of Subsurface Ocean Temperature from Surface Satellite Observations

Judged by oceanographers, so a good-looking RMSE number without physical interpretation will not survive questioning.
